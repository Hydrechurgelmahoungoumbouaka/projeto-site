# 💻 Plataforma de Cursos Online DevCurso 3D

> Um site moderno, minimalista e responsivo desenvolvido para a apresentação e venda de cursos práticos de desenvolvimento web (HTML5 e CSS3).

---

## 🎨 Sobre o Projeto

O **DevCurso 3D** é um projeto completo de Landing Page estruturado de forma semântica e estilizado seguindo a estética estética de design minimalista com tons terrosos (marrom fosco e bege claro), inspirado no conceito *Claymorphism 3D*. A plataforma conta com navegação interna dinâmica dividida em seções estratégicas de conversão.

### 📄 Páginas Integradas:
*   **Início (`index.html`):** Tela de apresentação principal (*Hero Section*) com chamada de impacto, ilustrações técnicas modernas e uma seção exclusiva sobre o instrutor.
*   **Aulas (`aulas.html`):** Cronograma completo do curso dividido por módulos expansíveis com detalhamento de minutagem de cada aula.
*   **Preço (`preco.html`):** Cards estilizados com tabelas de planos e benefícios, além de efeitos interativos de clique em JavaScript.

---

## 🛠️ Tecnologias Utilizadas

O desenvolvimento do portal foi realizado utilizando ferramentas nativas e boas práticas da web, dispensando frameworks pesados:
*   **HTML5 Semântico:** Estruturação limpa voltada para SEO e acessibilidade.
*   **CSS3 Customizado:** Estilização baseada em Flexbox Layout, transições de estado (`:hover`), responsividade adaptada para dispositivos móveis e paleta monocromática terrosa.
*   **JavaScript Assíncrono:** Manipulação simples do DOM para simulação de fluxo de pagamentos e tratamento de eventos de cliques sem recarregamento estático.

## 🚀 Como Executar Localmente

Como o projeto utiliza tecnologias fundamentais da web, não é necessária nenhuma instalação complexa de pacotes de servidor:

1. Clone este repositório na sua máquina de desenvolvimento:
   ```bash
   https://github.com/Hydrechurgelmahoungoumbouaka/projeto-site.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd projeto-site
   ```
3. Abra o arquivo principal direto no seu navegador de preferência:
   ```bash
   # No Linux (Ubuntu/Debian)
   xdg-open index.html
   ```
