Perguntas Frequentes

Preciso ter experiência prévia com programação?

Não! O curso começa desde como a internet funciona e a instalação do VS Code até projetos completos em HTML5 e CSS3.

Como funciona a emissão do certificado?

Assim que você concluir 100% das aulas na aba Grade de Aulas, o botão de certificado é liberado automaticamente para salvar em PDF ou imprimir.

Posso praticar código direto pelo navegador?

Sim! Acesse a aba Praticar no menu superior para testar códigos HTML e CSS em tempo real sem precisar instalar nada.
